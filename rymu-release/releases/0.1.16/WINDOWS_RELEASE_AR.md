# Windows 0.1.16 — إلغاء تسجيل الدخول

يعالج هذا الإصدار عدم وجود زر إلغاء أثناء انتظار تسجيل الدخول في المتصفح. يظهر «إلغاء تسجيل الدخول» أثناء طلب الحساب، وانتظار المتصفح، وربط الجهاز، ثم تظهر إمكانية المحاولة مجدداً. يغلق الإلغاء مستمع الرجوع المحلي وطلبات هذه المحاولة فقط؛ لا يحذف بيانات حساب محفوظة مسبقاً. تُرفض نتيجة أي محاولة ملغاة قبل اعتماد بيانات الجهاز أو حفظ الجلسة، حتى إذا وصلت متأخرة. لا يعني الإلغاء التراجع عن عملية قد اكتملت بالفعل على الخادم.

حدود التغيير بعد مراجعة تقليل الفروق:

- `apps/native/flutter/lib/rymu/windows_account.dart`: حالة محاولة تسجيل الدخول، إغلاق طلباتها ومستمعها، والتحقق من صلاحية المحاولة قبل اعتماد نتائجها. عميل طلبات التجديد العادية لم يتغير؛ يتلقى مسار تسجيل الدخول عميلاً مستقلاً. يبقى منفذ الرجوع الإنتاجي49383، ويستعمل الاختبار منفذاً مؤقتاً لتجنب التطبيق الجاري.
- `apps/native/flutter/lib/rymu/windows_home.dart`: زر إلغاء فعال أثناء الانشغال، وحالة إعادة المحاولة، وعدم عرض الإلغاء الذي اختاره المستخدم كخطأ خدمة.
- `apps/native/flutter/test/rymu_windows_sign_in_cancel_test.dart`: ثلاث حالات فعلية على fixture محلي وواجهة Flutter، لا متصفح حقيقي أو حساب مالك.

نجحت الحالات الثلاث الجديدة و13 حالة دورة حياة ويندوز الحالية، دون تخطٍ، ثم أُعيدت الحالات الثلاث بنجاح بعد إضافة الحراس النهائية قبل تغيير الحالة وحفظ الجلسة. الفحص الساكن للملفات الثلاثة انتهى بـ`No issues found`. تغطي الاختبارات تحرير منفذ الرجوع وإعادة المحاولة، إلغاء ربط الجهاز مع تجاهل الرد المتأخر وحفظ بيانات الحساب القديمة، وظهور زر الإلغاء الفعال ثم زر المحاولة مجدداً. تستعمل ملفاً شخصياً خاصاً في `LOCALAPPDATA` وتعريف local-build للاختبار فقط.

تمت مقارنة1,192 ملفاً أصلياً بأرشيف المصدر العام0.1.15-2077؛ اختلف ملفا Dart المذكوران فقط، وأُضيف ملف الاختبار. بقيت مدخلات Rust/TOML/lock الـ393 مطابقة بعد تطبيع نهايات الأسطر. لذلك يعاد استخدام DLL0.1.14 الموثق ببصمة `d925ffa5a74e786b1d9630c9066dbb1046258d8eb378bff770cd831264e0fa2d`؛ لا توجد دعوى إعادة ترجمة Rust. Flutter AOT وC++ يُبنيان من المصدر المحدّث داخل مجلد مستقل، دون استبدال runner القديم أو تشغيل نافذة التطبيق أو المثبت.

إعداد الإنتاج هو `RYMU_ACCOUNT_API_BASE=https://rymu.iptvora-server.workers.dev/api/v1` و`RYMU_WINDOWS_VERSION=0.1.16` باستخدام `scripts/windows-flutter.mjs` وFlutter3.24.5. لا يمرر البناء الإنتاجي `--local` أو تعريف `RYMU_LOCAL_BUILD`. تبقى حزمة Android2077 كما هي. لم يُغيّر هذا العمل حساب المالك أو نسخة Store الموجودة أو أي نشر عام.

هذه اختبارات مكونات وبناء؛ لا تثبت اتصال peer حقيقياً أو إعادة تشغيل Windows أو نجاح WACK أو تثبيت MSIX. يبقى المثبت دون توقيع موثوق، وتبقى مراجعات تراخيص بعض المكونات وحدود provenance موثقة في ملفات تدقيق الإصدارات السابقة. تُجمع نصوص vcpkg الفعلية كما في0.1.15 دون اعتبار الجمع موافقة ترخيص شاملة.

اكتمل البناء المعزول فعلياً: البناء الأول الكامل لـFlutter/C++ استغرق 102.9 ثانية داخل Flutter، ثم أعيد البناء بعد الحراس الأربعة النهائية خلال 45.3 ثانية. انتهى MSBuild النهائي بصفر أخطاء وصفر تحذيرات. قرئت بيانات EXE الفعلية: `Rymu`، إصدار `0.1.16+0`، وناشر `Hussein Mlhem`، مع بقاء حقوق Purslane الأصلية. فُحص تعريف HTTPS الإنتاجي من الملف المولّد، وتطابقت بصمات المصدر المبني مع الملفات المختبرة.
